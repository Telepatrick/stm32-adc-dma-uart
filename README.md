# emb16-homework

## Домашнє завдання: DMA

### Хід роботи:
1. Зібрано апаратну систему на базі мікроконтролера STM32, підключено аналогові джерела до каналів АЦП (Channel 3 та Channel 4) та налаштовано інтерфейс UART для зв'язку з консоллю.
2. У проєкті реалізовано обробку даних за допомогою прямого доступу до пам'яті (DMA):
  - Зчитування з АЦП через DMA: Налаштовано буферизований збір масиву вибірок з АЦП у фоновому режимі без постійного завантаження центрального процесора;
  - Передача по UART через DMA: Задіяно асинхронну відправку відформатованих текстових пакетів у термінал;
  - Реалізація функціоналу осцилографа: Додано математичну обробку буфера вибірок для розрахунку ключових метрик сигналів у реальному часі: мінімальної напруги Vmin, максимальної напруги Vmax, розмаху Vpp та середнього значення Vavg для кожного з каналів.

### Результат:
Опановано технологію DMA для оптимізації роботи з периферією АЦП та UART на мікроконтролері STM32. Успішно запущено апаратний конвеєр збору вибірок, обчислення параметрів міні-осцилографа Vmin, Vmax, Vpp, Vavg та стабільний неблокуючий вивід результатів у консоль.
